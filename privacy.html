Política de Privacidade

BELLA TikTok Publisher e serviços relacionados.

Início Termos de Uso

Última atualização: 11 de agosto de 2026

A BellaTrend ("nós", "nosso") opera o aplicativo BELLA TikTok Publisher, ferramenta interna de gestão e publicação de conteúdo na plataforma TikTok. Esta política descreve como tratamos dados pessoais em conformidade com a LGPD (Lei nº 13.709/2018).

1. Controlador e contato

Controlador: BellaTrend
E-mail de privacidade: privacidade@bellatrend.com.br
Encarregado (DPO): privacidade@bellatrend.com.br

2. Dados que coletamos

  • Dados de autenticação TikTok (OAuth): identificador de usuário TikTok, nome de exibição, foto de perfil básica (scope user.info.basic).
  • Credenciais OAuth: tokens emitidos pelo TikTok após autorização explícita do titular (armazenados somente no ambiente operacional, nunca neste site).
  • Dados de publicação: metadados de vídeos enviados (caption, hashtags, status de publicação) — não armazenamos senha da conta TikTok.
  • Logs técnicos: eventos de auditoria (modo de operação, gates, erros) — sem credenciais.
  • Dados de contato: e-mail fornecido voluntariamente para suporte ou solicitações LGPD.

Não coletamos: senha TikTok, credenciais capturadas manualmente, dados de localização GPS do dispositivo, nem dados de terceiros não relacionados ao serviço.

3. OAuth TikTok e Login Kit

A autenticação utiliza exclusivamente o fluxo oficial TikTok Login Kit / OAuth 2.0. O usuário é redirecionado para a página de autorização TikTok, concede permissões (scopes) de forma granular e retorna via redirect URI registrada. Não simulamos login nem utilizamos automação de browser.

4. Tokens OAuth

  • Tokens de acesso usados para chamar a Content Posting API (creator info, init upload, status).
  • Tokens de renovação usados somente para renovar credenciais expiradas, via endpoint oficial TikTok.
  • Credenciais nunca são incluídas em repositório git público, relatórios públicos ou logs identificáveis.

5. Armazenamento e segurança

  • Tokens armazenados localmente no ambiente operacional BellaTrend, preferencialmente criptografados.
  • Segredos de aplicativo mantidos apenas em configuração privada do operador, nunca no código-fonte público.
  • Acesso restrito a operadores autorizados BellaTrend.

6. Finalidade e base legal

  • Publicação e upload de conteúdo autorizado pelo titular (execução de contrato / consentimento).
  • Gestão editorial e calendário de publicações (legítimo interesse, com gates de aprovação humana).
  • Conformidade com políticas TikTok for Developers (obrigação legal / contratual).

7. Compartilhamento

Compartilhamos dados apenas com TikTok (via APIs oficiais autorizadas) e infraestrutura necessária à operação. Não vendemos dados pessoais.

8. Retenção

Tokens: mantidos enquanto a integração estiver ativa ou até revogação. Logs de auditoria: até 12 meses. Metadados de publicação: conforme necessidade editorial.

9. Revogação de acesso

O titular pode revogar autorização a qualquer momento:

  • No app TikTok: Configurações → Segurança → Apps conectados → remover BellaTrend.
  • Solicitando desconexão ao operador BellaTrend via privacidade@bellatrend.com.br.

Após revogação, tokens locais são invalidados e removidos.

10. Exclusão de dados

Para solicitar exclusão de dados pessoais, envie e-mail para privacidade@bellatrend.com.br com assunto "LGPD — Exclusão de dados". Responderemos em até 15 dias úteis.

11. Direitos do titular (LGPD)

Confirmação, acesso, correção, anonimização, portabilidade, eliminação, informação sobre compartilhamento e revogação de consentimento — via privacidade@bellatrend.com.br.

12. Crianças e adolescentes

O serviço não se destina a menores de 18 anos. Não coletamos intencionalmente dados de menores.

13. Alterações

Esta política pode ser atualizada. A data de revisão será indicada no topo.
