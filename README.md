# BELLA TikTok Publisher — Public Review Site

## Purpose

Public landing page, Privacy Policy and Terms of Service required for **TikTok Developer App Review**.

This repository contains only static HTML and CSS. No application secrets, OAuth tokens, or backend code.

| `privacy.html` | Privacy Policy (LGPD) |
| `terms.html` | Terms of Service |
| `styles.css` | Shared stylesheet |
