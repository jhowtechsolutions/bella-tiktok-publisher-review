BELLA TikTok Publisher

Ferramenta interna de publicação e gestão de conteúdo via TikTok Content Posting API — com aprovação humana, calendário editorial e conformidade total com OAuth oficial.

Privacidade Termos

Gerenciamento de conteúdo

O BELLA TikTok Publisher integra o pipeline editorial BellaTrend com a conta TikTok autorizada. Cada vídeo passa por validação de qualidade, identidade geográfica (Jundiaí-SP) e pacote de publicação antes de qualquer envio.

Upload oficial

Utilizamos exclusivamente a TikTok Content Posting API para upload de vídeo (Direct Post ou Draft/Inbox). Não há automação de browser, simulação de login ou endpoints não documentados.

  • Direct Post — publicação quando auditado e elegível
  • Draft Upload — fallback para seleção manual de áudio/privacidade no app TikTok

Calendário editorial

Publicações seguem calendário editorial: horários planejados, timezone America/Sao_Paulo e estados PLANNED → READY → PUBLISHING → PUBLISHED.

Aprovação manual

Modos operacionais:

MANUAL

Operador informa caption, hashtags, privacidade e aprova cada publicação.

SEMIAUTOMATIC

Agente monta preview a partir dos artefatos; humano autoriza antes do envio.

AUTOMATIC

Somente com audit TikTok, gates completos e configuração explícita.

Integração oficial TikTok

Autenticação via Login Kit e OAuth 2.0. Scopes solicitados conforme função: video.publish, video.upload, user.info.basic. Credenciais OAuth armazenadas apenas no ambiente operacional autorizado; nunca neste site público.
